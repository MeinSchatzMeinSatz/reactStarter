# 렌더링 방법

- {} 중괄호 사용법
  JSX 중괄호는 JS와 HTML의 연결고리 역할을 하여 동적인 UI 작성을 가능하게 해주는 핵심 문법이다.

1. JS 표현식 삽입
   JSX 내에서 동적 값이나 로직 넣기
   `{변수}`

2. 배열 반복문 활용
   배열 데이터들을 JSX 요소로 변환하여 렌더링
   `{items.map(item => <li>{item}</li>)}`

3. 조건문 및 삼항 연산자 사용
   조건부 렌더링
   `{조건 ? <A /> : <B />}`

## 조건부 렌더링

조건에 따라 컴포넌트가 다른 내용, 다른 엘리먼트, 또는 아예 아무 것도 렌더링하지 않게 만들 수 있는 패턴이다.

- 상황 연산자 사용

```jsx
function	UserGreeting({ isLoggedIn }) {
	return (
		<div>
			{isLoggedIn ? “환영합니다!” : “로그인 해주세요.”}
		</div>
	);
}
```

isLoggedIn 값에 따라 “환영합니다.” 또는 “로그인 해주세요.”가 표시된다.

- if 문과 return
  조건 분기가 복잡할 때는 return을 여러 개 사용할 수 있다.

```jsx
function Welcome({ user }) {
  if (user) {
    return <h1>안녕하세요, {user.name}!</h1>;
  }
  return <h1>로그인이 필요합니다.</h1>;
}
```

- 논리 연산자(‘&&’) 사용
  조건이 참일 때만 요소를 보여주고 싶을 때 자주 사용.

```jsx
function Alert({ show }) {
	return (
		<div>
			{show && <p>경고 메시지: 입력값을 확인하세요!</p>
		</div>
	);
}
```

- 조건에 따라 컴포넌트 자체 교체

```jsx
function Main({ isAdmin }) {
  return isAdmin ? <AdminPanel /> : <UserPanel />;
}
```

## 리스트 렌더링

배열 형태의 데이터를 React에서 반복적으로 컴포넌트로 표현하는 방식.

- map 메서드로 반복

```jsx
function TodoList({ items }) {
  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>{item.text}</li>
      ))}
    </ul>
  );
}
```

- items 배열을 map으로 반복하며, 각 요소마다 ‘<li>’를 만든다.
- ‘key’ prop을 반드시 넘겨야 한다.(React가 항목의 고유성을 파악한다)

```jsx
// 예시) 사용자 목록
const users = [
	{ id: 1, name: “철수” }
	{ id: 2, name: “영희” }
];

function UserList() {
	return (
		<ul>
			{users.map(user => (
				<li key={user.id}>{user.name}</li>
			))}
		</ul>
	);
}
```

컴포넌트 리스트화 예시

```jsx
function Profile({ user }) {
  return (
    <div>
      {user.name} ({user.email})
    </div>
  );
}

function ProfileList({ users }) {
  return (
    <div>
      {users.map((u) => (
        <Profile user={u} key={u.id} />
      ))}
    </div>
  );
}
```

보충 팁

- 조건부 렌더링과 리스트 렌더링은 서로 조합할 수도 있다.
  - 예: ‘item.length > 0 ? …. ; …’
- 리스트의 각 요소에는 꼭 고유한 key prop을 달아야 React가 내부적으로 최적화 한다.
- 조건부 렌더링에서 일부 요소만 숨기고 싶으면 CSS로 처리하는 대신, JSX 내부에서 아예 렌더링 하지 않는 게 성능에 더 좋음.
